# quadra-check

ソシオニクス **クアドラ特化** の行動観察型診断。

従来の4クアドラに、日本ソシオニクス協会「モデルK」のサブクアドラを加えた **8クアドラ** で判定します。

| クアドラ | テーマ | 派生元 |
|---|---|---|
| アルファ（α） | 創世記 | — |
| ベータ（β） | 帝国 | — |
| ガンマ（γ） | 市場 | — |
| デルタ（δ） | 伝統 | — |
| オメガ（Ω） | 特権社会 | ガンマ |
| サイ（Ψ） | 市民社会 | デルタ |
| カイ（Χ） | ユートピア | アルファ |
| ファイ（Φ） | 革命 | ベータ |

結果には **アンチクアドラ**（あなたの価値観と最も反対のクアドラ文化）も表示します。

質問への回答内容だけでなく、操作や反応そのものを観測する「行動観察型」の設計です（もふみつ工房の既存診断シリーズと同じ手法）。
